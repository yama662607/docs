# 01. 普遍的デザイン原則（知覚・認知科学・情報デザイン）

ジャンル（学術・ビジネス・講義）を問わず、すべてのスライドに適用される普遍的な原則です。  
特定のジャンルで例外が必要な場合（例：読む用コンサル資料の情報密度）のみ、ジャンル別プロファイル（[02-genre-profiles-and-visual-system.md](./02-genre-profiles-and-visual-system.md)）が優先されます。

---

## 最上位の3原則

迷ったときは、以下の3つのメタ原則で判断します。

1. **外因性認知負荷を最小化する**
   - 聴衆のワーキングメモリは会場で最も希少な資源です。メッセージに貢献しない装飾、重複した文字、微妙にズレた枠線はすべて「読む・探す・解釈する」ための無駄な負荷（外因性負荷）になります（Sweller の認知負荷理論 / Mayer の一貫性・冗長性原理）。
2. **1スライド＝1メッセージ、かつ主張を明示する**
   - 聴衆に「要するに何が言いたいのか」を推測させないでください（Mayer のセグメンテーション原理 / Duarte の Big Idea / Assertion-Evidence 研究）。
3. **知覚の物理的限界を尊重する**
   - 最後列から読めない文字、見分けられない色、まとまりが伝わらない配置は、存在しないのと同じです（タイポグラフィ / WCAG コントラスト / Gestalt 原理）。

## 1. 知覚レイヤー（タイポグラフィ・レイアウト・色）

### タイポグラフィ
- **ジャンプ率（タイプスケール）**：見出しは本文の **1.3〜2.0倍** に設定し、階層を一目で判別させます。同じ役割の要素は全スライドで同じサイズ・ウェイトにします。
- **フォントサイズと可読距離（8Hルール）**：
  - 投影用本文は **18pt以上（推奨20〜24pt）**、タイトルは **28〜44pt**（日本語の標準デッキでは見出し24–28pt、本文18–20ptも実務基準）。
  - 「8Hルール」では、最後列の席がスクリーン高さの8倍以内にある場合、文字高はスクリーン高の1/50以上が必要とされます。「枠に入るから小さくする」のはファイル向けの設計であり、会場向けの設計ではありません。
- **行間**：欧文は **1.4〜1.6倍**、日本語は字面が大きいため **1.15〜1.3倍** が目安。1.0倍のベタ詰めは避けます。
- **書体**：投影・スクリーン表示は **サンセリフ体／ゴシック体** を基本にします（明朝体・セリフ体の細い線はプロジェクターで潰れやすい）。
- **下線（アンダーライン）強調の禁止**：下線は欧文のディセンダ（`g`, `p`, `y` 等の下向きの線）を分断し、文字認識を損ないます（Kosslyn）。強調は「太字」「サイズ」「アクセントカラー」の **いずれか1つ** に絞り、統一して使います。

### レイアウト（ゲシュタルト原理の活用）
- **近接（Proximity）＝グルーピング**：関連する要素は近づけ、無関係なグループ同士は余白で明確に離します。グループ間の空きと項目間の空きが同じだと、構造が消えます。
- **類同（Similarity）＝カテゴリ**：同じ役割の要素は同じ色・形・サイズに揃えます。同列のカードやアイコンのスタイルをバラバラにすると、別の意味だと誤解されます。
- **図と地（Figure-Ground）**：前景の情報（図）と背景（地）のコントラストを十分に確保します。模様や写真の上に直接文字を乗せないようにします。
- **整列とグリッド**：すべての要素を共通のグリッド線に揃えます。わずかなズレは視覚探索コストを増やし、内容の信頼感も損ないます（処理流暢性の低下）。
- **余白（ホワイトスペース）**：余白は「埋めるべき空き地」ではなく、グループを分け目を休ませる設計要素です。

### 色彩設計
- **60-30-10 の法則**：約60%を基調色（背景等の中立色）、約30%を構造・従属色、約10%をアクセント色にします。アクセント色は「本当に注目してほしい箇所」だけに限定します。強調色だらけは「強調なし」と同じです。
- **1色＝1意味**：デッキ全体で色の意味を固定します（例：深紺＝構造・フィット曲線、朱色＝主役のデータ・数値、赤＝問題・警告のみ）。
- **WCAG コントラスト基準を最低ラインとする**：
  - 通常テキスト：**4.5:1 以上**
  - 大きい文字（18pt以上または太字14pt以上）および図表要素：**3:1 以上**
  - プロジェクターや明るい照明の会議室はモニターより条件が悪いため、迷ったら文字を濃くします。
- **色だけで意味を伝えない**：男性の約8%（約1/12）、女性の約0.5%に色覚多様性があり、白黒印刷・投影の場面もあります。色と同時に「形状」「ラベル」「矢印・記号」「位置」を併用します。

## 2. 認知科学レイヤー（Mayer / Sweller / Kosslyn / Tufte）

### Richard Mayer のマルチメディア学習12原理（スライド設計への直結部）
1. **一貫性（Coherence）**：メッセージと無関係な装飾画像・効果音・クリップアート・chartjunk（3D棒グラフ、太いグリッド、データのグラデーション塗り）を削るほど理解が上がります。Tufte の **data-ink ratio**（インクの総量のうちデータを表す比率を最大化する）と同根です。
2. **冗長性（Redundancy）**：スライドの文章をそのまま読み上げる（画面テキスト＋ナレーションで同一内容を重複させる）と、視覚と聴覚の両チャネルが同じ処理で競合し、理解がむしろ下がります（聴衆は毎分約200語読み、話者は約100語で話すためズレが生じる）。**スライドは「主張と証拠」、声は「説明」** を担います。
3. **空間的近接（Spatial Contiguity）**：ラベルは対象の上またはすぐ隣に置きます。グラフの凡例を離れた隅に置かず、線の横に直接ラベル付けすると視線移動（Split-Attention 効果）を防げます。キャプションは図の直下に置きます。
4. **時間的近接（Temporal Contiguity）**：アニメーションや段階表示を使う場合は、口頭で言及するタイミングと同期させます。
5. **信号化（Signaling）**：構造や視線の行き先を示す見出し・矢印・アクセント色は学習を助ける「良い追加」です。
6. **セグメンテーション（Segmenting）＆ 事前学習（Pre-training）**：情報量が多いときは1枚に詰め込まず分割し、複雑な図や式の前に主要用語・記号を先に導入します。

### 認知負荷理論（Sweller）と負荷バランス
- **内因性負荷（題材自体の難しさ）が高いほど、提示形式（外因性負荷）はシンプルにしなければなりません。** 内容の複雑さと見た目の複雑さは足し算ではなく掛け算で聴衆を圧迫します。
- 聴衆の予備知識にない専門用語・記号を説明なしで出すと、内因性負荷が急上昇します。初出で定義するか、使わない判断をします。

### Kosslyn の互換性と弁別性
- **互換性（Compatibility）**：表現の向き・色と意味を一致させます（増加＝上向き、悪化・警告＝注意色、時間＝左から右）。「改善しているのに下向き矢印」「良い数値が赤」などは誤読を招きます。
- **弁別性（Discriminability）と卓立性（Salience）**：人の目は大きな知覚差に向きます。違いを示すなら比率として十分な差をつけ、差のない装飾で注意を奪わないようにします。

### Tufte の『The Cognitive Style of PowerPoint』の教訓
- アウトライン的な箇条書き階層は、本来複雑な因果関係や数値の重みを不自然に圧縮・曖昧にします（コロンビア号事故調査報告書でも、技術文書の代わりに箇条書きスライドに依存した問題が指摘されました）。
- 複雑な関係やデータは浅い箇条書きに押し込めず、図・表・適切な文章構造で表現します。

## 3. メッセージ・プレゼン設計論（Duarte / Reynolds / Alley）

### Assertion-Evidence 型スライド
- **Michael Alley（Penn State）**：スライドタイトルをトピック名（例：`Results`, `概要`）ではなく**完全な主張文（Assertion）**にし、本文には箇条書きの言い換えではなく**その主張を証明する視覚的証拠（図表・写真・模式図・数式）**を置きます。
- **実証的裏付け**：Garner & Alley (2013, *Int'l J. Engineering Education*, n=110) では、Assertion-Evidence 群が従来型（トピック見出し＋箇条書き）に比べ、複雑な概念の理解度が高く、誤概念が少なく、知覚的認知負荷が低く、遅延再生成績も優れていました（追試：Wolfe et al., 2024）。
- **境界条件の注意**：この優位性は「複雑な概念の理解」で顕著であり、単純な数値リストの短期記憶や一覧表では従来型が適する場合もあります。単純なアジェンダや一覧を無理に不自然な主張文へねじ曲げる必要はありません。

### Glance Test（Duarte）と抑制（Reynolds）
- **Glance Test（3秒ルール）**：スライドは道路標識のような「一瞥メディア」です。**約3秒で構造と要点が掴める**か確認し、各要素が「シグナル」か「ノイズ」かを判定します（`slide:ology`）。
- **Big Idea と「So What?」**：プレゼン全体の核（Big Idea）に繋がらないスライドは本編から外します。すべてのスライドは「だから何なのか（So What?）」に答えられなければなりません。
- **抑制・削減・強調（Reynolds, `Presentation Zen`）**：足し算ではなく引き算で、本当に必要な要素だけを残して際立たせます。

## 4. 普遍的禁止事項リスト（15項目・理由付き）

| # | 禁止事項 | 違反する原理 | なぜ問題か |
|---|---|---|---|
| 1 | **スライドの全文をそのまま読み上げる** | Mayer 冗長性原理 / CLT | 視覚と聴覚で同じ情報を二重処理させ、理解度が下がる |
| 2 | **1枚に複数の主張・トピックを詰め込む** | セグメンテーション / CLT / Big Idea | ワーキングメモリ（約4チャンク）を超過し優先度が曖昧になる |
| 3 | **「Results」「考察」等のトピック見出しのみ** | Assertion-Evidence / 信号化 | 聴衆が自分で結論を推論する負担が増え、記憶定着も落ちる |
| 4 | **無関係な装飾（クリップアート・効果・chartjunk）** | Mayer 一貫性 / Tufte data-ink | 注意を逸らし、データ伝達に使える視覚帯域を希釈する |
| 5 | **入らないから文字を小さくする（投影18pt未満の本文）** | 可読距離・8Hルール / 弁別性 | 後ろの席から読めない文字は情報として存在しないのと同じ |
| 6 | **低コントラスト配色（薄い文字、パステル同士）** | WCAG 基準（4.5:1 / 3:1） | 照明やプロジェクターで視認不能になり、アクセシビリティも損なう |
| 7 | **色だけで意味を伝える** | WCAG / 色覚多様性 | 色覚特性や白黒印刷で情報が完全に欠落する |
| 8 | **図とラベル・凡例を離して置く** | Mayer 空間的近接 | 視線往復（Split-Attention）で統合理解が阻害される |
| 9 | **関連要素と無関係要素を同じ間隔で並べる** | Gestalt 近接・類同 | 脳が誤ったグルーピングを行い、構造を誤解させる |
| 10 | **整列・グリッドの無視** | グリッド理論 / 処理流暢性 | 視覚探索コストが増え、資料全体の信頼性が落ちて見える |
| 11 | **下線（アンダーライン）での強調** | Kosslyn 弁別性 | ディセンダ（g, p, y 等）を分断し文字認識を遅らせる |
| 12 | **すべてを強調する（全太字・多色乱用）** | 卓立性 / コントラスト | 相対差が消え、実質「何も強調されていない」状態になる |
| 13 | **階層のないフラットな画面** | 視覚階層 / 卓立性 | 最初に見る入口がなく、聴衆が重要度を推測する羽目になる |
| 14 | **未定義の専門用語・記号の多用** | CLT 内因性負荷 / 適切な知識 | 前提ギャップで負荷が跳ね上がり、後続の理解が止まる |
| 15 | **意味と表現形式の矛盾** | Kosslyn 互換性 | 「改善なのに下向き矢印」「良いのに赤」等で誤読を誘発する |
